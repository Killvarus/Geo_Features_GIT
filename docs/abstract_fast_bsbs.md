# Введение

Обратные задачи (ОЗ) оптической спектроскопии заключаются в определении состава образца по его спектрам и часто решаются с помощью нейронных сетей (НС) [1]. Входными признаками служат интенсивности в каналах спектра: их число достигает нескольких тысяч, а соседние каналы сильно коррелированы. Мультиколлинеарность и избыточность признаков обусловливают необходимость их отбора [1, 2].

*Методы-обёртки* оценивают значимость признака по изменению ошибки модели при его исключении [3], что требует обучения большого числа моделей. В работе [4] был предложен алгоритм *Batch Sequential Backward Selection* (BSBS), исключающий на каждой итерации сразу группу наименее значимых признаков. Это позволяет радикально сократить число итераций, однако количество вычислений внутри итерации не меняется: для оценки значимости каждого оставшегося признака обучается отдельная модель.

Настоящая работа посвящена ускорению алгоритма BSBS без изменения результата. Обучение отдельных моделей заменяется точным аналитическим пересчётом ошибки, при котором все модели одной итерации выражаются через одно обращение матрицы.

# Постановка задачи

## Экспериментальные данные

Алгоритм исследовался на шестипараметрической (6П) ОЗ определения концентраций ионов в воде по матрицам возбуждения–испускания фотолюминесценции (ФЛ) углеродных точек (УТ) [5]. Массив данных содержит 3125 водных растворов УТ (концентрация 5 мг/л) с нитратами катионов в различном сочетании:

- концентрации катионов $\mathrm{Cu^{2+}}$, $\mathrm{Ni^{2+}}$, $\mathrm{Al^{3+}}$, $\mathrm{Co^{2+}}$, $\mathrm{Cr^{3+}}$ изменялись от 0 до 6 мМ с шагом 1.5 мМ;
- концентрация аниона $\mathrm{NO_3^-}$ зависела от них и изменялась от 0 до 72 мМ;
- возбуждение ФЛ проводилось на 27 длинах волн от 280 до 410 нм;
- испускание регистрировалось на 201 длине волны от 375 до 575 нм, что даёт 5427 входных признаков.

## Нейросетевое решение

Массив разделён на тренировочный, валидационный и тестовый наборы (2225, 600 и 300 примеров). Применялось *автономное определение параметров*: для каждого из шести ионов отбор и обучение проводились отдельно. Отобранные наборы проверялись при решении ОЗ многослойным персептроном (МСП) с одним скрытым слоем из 32 нейронов.

# Ускоренный алгоритм

## Модель в основе BSBS

Признаков в задаче больше, чем примеров, поэтому линейная регрессия без регуляризации, использованная в [4], здесь неприменима: матрица $X^TX$ вырождена. В качестве модели, лежащей в основе алгоритма BSBS, использовалась *гребневая регрессия* [6] с коэффициентом $\alpha = 700$, выбранным по ошибке на валидационном наборе. Значимость признаков оценивается этой линейной моделью.

## Пересчёт ошибки без обучения моделей

Пусть $A = X^TX + \alpha I$, а $\beta = A^{-1}X^Ty$ — решение на текущем наборе из $p$ признаков. Исключение признака $j$ равносильно условию $\beta_j = 0$, и метод множителей Лагранжа даёт выражение для нового решения:

$$
\beta^{(j)} = \beta - c_j\,(A^{-1})_{\cdot j}, \qquad c_j = \frac{\beta_j}{(A^{-1})_{jj}}.
$$

Тогда на отложенной части данных $(X_e, y_e)$ при остатке $r = y_e - X_e\beta$ и матрице $M = X_eA^{-1}$ сумма квадратов ошибок модели без признака $j$ равна

$$
S_j = \|r\|^2 + 2c_j\, r^TM_{\cdot j} + c_j^2\,\|M_{\cdot j}\|^2.
$$

Все $p$ значений $S_j$ вычисляются за $O(p^3 + n_e p^2)$ операций, где $n_e$ — число отложенных примеров, тогда как обучение $p$ отдельных моделей даже при заранее вычисленных матрицах требует $O(p\,\min(p,n)^3)$ операций, где $n$ — число обучающих примеров. Близкий приём применялся для ускорения отбора с последовательным добавлением признаков [7].

## Шаги алгоритма

1. На каждом из 5 разбиений тренировочного набора вычисляются матрица $A^{-1}$ для текущего набора признаков и значения $S_j$.
2. Значения $S_j$ суммируются по разбиениям. Значимость признака определяется приростом ошибки при его исключении.
3. Одновременно исключаются 10% оставшихся признаков с наименьшей значимостью.

Матрицы $X^TX$ вычисляются один раз, на следующих итерациях из них выбираются строки и столбцы текущего набора.

# Результаты

## Время счёта

Ускоренный алгоритм сравнивался с исходным в одной конфигурации: один поток, один ион, 5427 признаков, пакет 10%. Время полного отбора составило:

- **194 с** для ускоренного алгоритма: 330 обращений матрицы вместо обучения почти 270 тысяч моделей;
- **9.2 ч** для исходного алгоритма с заранее вычисленными матрицами $X^TX$ или $XX^T$, что в 170 раз дольше;
- **47 ч** для исходного алгоритма с обучением каждой модели с нуля, что в 870 раз дольше.

Оценки для исходного алгоритма получены по времени обучения одной модели, измеренному при 9 значениях $p$. Выигрыш растёт с числом признаков: при полном выполнении обоих алгоритмов на 150, 300 и 600 каналах он составил 17, 28 и 88 раз относительно варианта с заранее вычисленными матрицами. Ускорение делает доступным и уменьшение пакета: исключение признаков по одному заняло бы, по оценке, 18 часов вместо 128 суток.

## Совпадение с исходным алгоритмом

При 150, 300 и 600 признаках ранжирования, полученные обоими алгоритмами, совпали полностью. На более чем 900 выборочных моделях при $p$ от 30 до 5427 относительное расхождение значений $S_j$ не превысило $10^{-14}$, то есть уровня ошибок округления.

# Выводы

В работе предложен ускоренный вариант алгоритма BSBS на основе гребневой регрессии, в котором обучение отдельных моделей заменено точным аналитическим пересчётом ошибки. По итогам работы можно сделать следующие выводы.

1. На 6П ОЗ с 5427 признаками время полного отбора сократилось примерно до 3 минут: примерно в 170 раз относительно исходного алгоритма с заранее вычисленными матрицами и примерно в 870 раз относительно обучения каждой модели с нуля. Выигрыш растёт с числом признаков.
2. Результат совпадает с результатом исходного алгоритма с точностью до ошибок округления, поэтому ускорение не связано с потерей качества отбора.
